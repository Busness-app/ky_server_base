## Ky Server Base

This is to be a base build with all the things needed to start a new Busnes.app product.
All Busness.app products are Cloud Mobile first, with PWA and website wrapper app using existing QR code linking tech.
It should support SSO, though all normal SSO products including KySignOn.
It should support KyBackup as a feature 0.
It should support SCIM based provisioning.
It should allow swapping of DBs to a heavier DB on demand.
It should folow the KySecurity Color Pallets with theme selection.
